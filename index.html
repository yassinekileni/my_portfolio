Enterprise Security & IPsec

Multi-Site Secure Enterprise Network

3-Site Full-Mesh IPsec VPN with SVI Access Control Lists & SMB Demonstration

Designed, configured, and validated a complete multi-site enterprise network infrastructure in EVE-NG interconnecting a Headquarters and two Branch locations through a simulated public Internet WAN.

Key Accomplishments:

  • Full-Mesh IPsec Overlay: Configured IKEv2 policy, AES-256 encryption, SHA-256 integrity, DH Group 14, and pre-shared key authentication across ASAv firewalls.
  • Departmental Segmentation: Built VLAN 10 (HR), VLAN 20 (Finance), and VLAN 30 (IT) at each site with Layer 3 SVI gateways on Cisco switches.
  • Access Control Lists: Applied inbound SVI extended ACLs enforcing strict same-department communication across sites while blocking cross-department lateral movement.
  • Verification & Failover: Executed controlled WAN link shutdowns to prove automatic IKEv2 tunnel recovery, inspected ASA Syslog buffered logs, and demonstrated authenticated Windows SMB file sharing across the encrypted tunnel.
